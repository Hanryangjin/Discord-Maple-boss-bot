# 메이플스토리 보스 파티 배분 봇

Python 3.11+ / discord.py 2.6.4 / SQLite 단일 프로세스 MVP입니다. 구현 기준은 [기획안 v2.2](docs/plan-v2.2.md)이며 [구현 대조표](docs/implementation.md)에 차이·검증 제한을 기록했습니다.

## 설치와 실행

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m maplebot --check
.venv/bin/python -m unittest discover -v
```

Windows에서는 [토큰·테스트 서버 ID 영구 설정 안내](docs/local-settings.md)에 따라 최초 한 번 등록하면 됩니다. 다른 환경에서는 `DISCORD_TOKEN`을 실행 환경에 안전하게 주입한 뒤 실행합니다. `.env.example`은 변수 안내용이며 `.env` 파일을 자동으로 읽지는 않습니다. 토큰을 저장소나 명령어 인수에 넣지 마세요.

```bash
.venv/bin/python -m maplebot
```

- `DISCORD_TOKEN`: 봇 토큰. Windows에서는 미설정 시 자격 증명 관리자에서 조회
- `DISCORD_TEST_GUILD_ID`: 선택. 지정하면 테스트 서버에만 명령어 동기화. 환경 변수가 없으면 로컬 설정 사용
- `MAPLEBOT_CONFIG`: 선택. 로컬 설정 경로, 기본 `config.local.json` (실행 디렉터리 기준)
- `MAPLEBOT_JOB_ICONS`: 기본 `assets/jobs`. 선택적인 [직업 아이콘 교체 방법](assets/jobs/README.md). 기본 48개 SD 얼굴 이미지는 내장되어 별도 다운로드가 필요 없습니다.
- `MAPLEBOT_DB`: 기본 `var/maplebot.sqlite3`
- `MAPLEBOT_BACKUPS`: 기본 `var/backups`. 시작 전·실행 중 하루마다 SQLite backup API로 백업
- `DISCORD_PROXY`: 선택 HTTPS 프록시. REST 및 Gateway websocket 접근이 모두 필요

Discord Developer Portal에서 **Server Members Intent**를 활성화하세요. 서버 설치 범위는 `bot`, `applications.commands`입니다. 게시 채널에는 채널 보기, 메시지 보내기, Embed 링크, 메시지 기록 보기 권한이 필요합니다. 관리자 권한을 봇에 부여할 필요는 없습니다. 이 봇은 자신의 메시지만 수정·삭제합니다.

클라우드의 패키지 설치 허용 목록만으로 Discord 실연동이 가능해지는 것은 아닙니다. Discord REST·Gateway 대상 접근과 토큰이 별도로 필요합니다. 웹 미리보기는 제공하지 않습니다.

## 초기 운영

1. 서버 관리자가 `/설정 관리자역할`, `/설정 파티배분표채널`을 설정합니다.
2. `/직업 목록`을 확인합니다. 누락된 직업은 서버 관리자가 `/직업 추가`로 등록합니다.
3. `/보스 추가`로 보스를 등록합니다. 생성 직후 파티는 0개입니다.
4. `/캐릭터 등록`에서 직업을 자동완성으로 선택합니다. 관리자는 `소유자`를 지정해 대리 등록할 수 있습니다.
5. `/파티 생성`, `/파티 멤버추가`로 구성합니다. 또는 `/관리 패널`을 이용합니다.
6. `/파티배분표 게시`의 확인을 승인합니다. 게시와 이후 갱신은 영속 작업자가 처리합니다.
7. `/설정 조회`에서 게시 준비·오류·정리 실패 상태를 확인합니다.

헥환은 **만 단위**로 입력합니다. `5.25` → `5.25만` 표시, `52500` 저장. `52500`을 입력하면 52500만을 뜻하므로 단위에 주의하세요. `만` 문자는 붙이지 않습니다. 미등록은 0과 다릅니다.

## 명령어

| 그룹 | 하위 명령 |
|---|---|
| 설정 | 관리자역할, 파티배분표채널, 조회 |
| 직업 | 목록, 추가, 이름변경, 비활성화, 활성화 |
| 보스 | 추가, 목록, 수정, 순서, 비활성화, 활성화, 삭제, 복구, 현황 |
| 캐릭터 | 등록, 수정, 소유자변경, 목록, 조회, 비활성화, 활성화 |
| 파티 | 생성, 이름변경, 삭제, 멤버추가, 멤버제외, 이동, 병합 |
| 파티배분표 | 게시, 새로고침, 중단 |
| 관리 | 패널 |
| 내보스 | 본인 전체 캐릭터 조회 |

모든 운영 명령은 서버 전용입니다. 명령어와 버튼·모달 모두 실행 시 권한을 검사합니다. 확인 버튼은 5분 후 만료되며 중복 실행을 차단합니다. 개인 관리 화면은 하나의 메시지 안에서 전환됩니다. 뒤로·관리 홈·닫기를 제공하며, 5분 무조작 시 만료됩니다. 재시작 후 `/관리 패널`로 다시 여세요. 공개 파티 배분표는 제목·파티별 카드·아바타·편집/삭제 버튼을 표시합니다. 작은 직업 SD 얼굴 아이콘과 큰 Discord 아바타를 합성해 표시합니다. 사용자 추가 직업이나 자료가 없는 직업은 공통 대체 이미지를 사용합니다. 직업명을 수정해도 이미지 연결은 유지합니다. 공개 화면은 가능한 많은 파티를 이어서 표시하며, 2인 파티 3개는 한 메시지에 표시할 수 있습니다. Discord 한도를 넘는 경우에만 연속 메시지로 나누고 큰 보스 제목은 반복하지 않습니다. 공개 버튼은 재시작 후에도 동작하도록 등록합니다. [UI 개선 및 적용 안내](docs/ui-update.md)를 참고하세요.

## 운영·백업

DB는 봇 프로세스 하나에서만 사용하세요. 실제 배포에서는 DB와 백업 디렉터리를 영속 볼륨에 두세요. 스키마 초기화는 버전 1로 제공되며 향후 변경은 마이그레이션을 추가해야 합니다. 감사 로그는 변경 전후 서버 데이터를 보존하므로 DB·백업 접근 권한을 관리하세요.

```bash
.venv/bin/python -m maplebot --backup var/manual-backups
```

복원은 봇을 종료한 뒤 수행합니다. 현재 DB와 `-wal`·`-shm` 파일을 보존 위치로 옮기고 검증된 백업을 `MAPLEBOT_DB` 경로에 복사한 후 시작하세요. 실행 중 DB 파일을 덮어쓰지 마세요. 백업에는 로그·캐릭터·게시 작업이 포함되지만 외부 Discord 메시지는 포함되지 않습니다. 과거 백업 복원 후에는 `/파티배분표 새로고침`으로 Discord 상태를 다시 맞추고 고아 게시물을 확인하세요.

## 검증 상태

자동 테스트는 실제 SQLite, 애플리케이션 서비스, Discord 명령 정의 및 전송 모형을 사용합니다. 실제 Discord 로그인·서버 권한·Gateway 이벤트·버튼 UX는 토큰과 테스트 서버가 필요합니다. 현재 실행 결과와 남은 제한은 [검증 보고서](docs/implementation.md)를 참고하세요.

## 공개 배분표 보스 순서 변경

관리자 명령으로 보스를 원하는 위치로 옮길 수 있습니다. 위치는 활성 보스 목록에서 1부터 시작합니다.

```text
/보스 순서 보스:스우(익스트림) 위치:1
```

확인 후 해당 보스를 1번째로 이동하고 나머지 보스는 자동으로 한 칸씩 이동합니다. `/보스 수정 표시순서:…`도 같은 위치 지정 방식으로 동작합니다. `/보스 목록`에서 현재 순서를 확인하거나 관리 패널의 **보스 순서 → 위로/아래로/위치 직접 지정**을 사용하세요.

Discord는 기존 메시지의 위치를 이동할 수 없으므로, 게시 중이면 새 순서로 전체 배분표를 준비한 뒤 이전 게시물을 정리합니다. 이때 메시지 링크는 바뀌고 작업 중 잠시 두 배분표가 함께 보일 수 있습니다. 완료 전 추가 순서 변경은 차단합니다. 준비 실패 시 기존 게시물을 보존하며 `/설정 조회`에서 오류를 확인할 수 있습니다. 권한 오류가 있는 순서 복구는 약 60초 간격으로 다시 시도합니다.

비활성·삭제 보스는 순서 지정 대상에서 제외합니다. 새 보스나 재활성화한 보스는 마지막에 배치합니다. 메시지 삭제·페이지 증가로 보스 순서가 달라져도 작업자가 새 게시 세대로 정렬을 복구합니다. 다른 사용자가 작성한 메시지의 위치는 바꾸지 않습니다.

# 직업 SD 얼굴 아이콘

기본 직업 48개의 SD 얼굴 이미지가 패키지에 포함되어 있어 따로 내려받을 필요가 없습니다. 직업명을 바꾸어도 기존 이미지 연결은 유지됩니다. 관리자가 직접 추가한 직업은 기존 기본 직업과 같은 이름이어도 공통 `?` 대체 이미지를 사용합니다. 자료 누락·손상 시에도 같은 대체 이미지를 사용하며 Discord 아바타 합성 없이 직업 아이콘만 정사각형으로 표시됩니다. 소유자는 멘션으로 구분합니다.

특정 직업의 이미지를 직접 지정하려면 다음 위치에 파일을 넣으세요. 같은 서버에서 해당 직업을 사용하는 모든 캐릭터에 적용됩니다.

```text
assets/jobs/<서버ID>/<직업ID>.png
```

직업ID는 캐릭터ID나 직업명이 아닌 DB `jobs.id` 값입니다. 예를 들어 서버ID가 `123456789`, 직업ID가 `12`라면 `assets/jobs/123456789/12.png`입니다. 관리자용 SQLite 도구로 아래 조회만 실행하여 확인할 수 있습니다.

```sql
SELECT guild_id, id, name, icon_key FROM jobs ORDER BY guild_id, id;
```

`MAPLEBOT_JOB_ICONS`로 폴더를 변경할 수 있습니다. 상대 경로는 봇 실행 디렉터리 기준입니다. 서버·직업 ID 파일 → 내장 SD 이미지 → 공통 대체 이미지 순서로 선택합니다. 이름 기반 검색은 하지 않습니다. PNG·WebP·JPEG·GIF를 지원하며 애니메이션은 첫 프레임을 사용합니다. 여러 확장자가 있으면 png, webp, jpg, jpeg, gif 순서로 선택합니다. 손상된 지정 파일은 공통 대체 이미지로 표시됩니다.

이미지당 최대 5MiB·약 419만 화소이며 폴더 바깥을 가리키는 심볼릭 링크는 읽지 않습니다. 정사각형 얼굴 PNG를 권장합니다. 직접 지정하는 파일에는 내장 자료의 자르기 좌표를 적용하지 않습니다. 파일을 배치하거나 교체한 후 `/파티배분표 새로고침`을 실행하고 관리 화면을 다시 여세요. 직접 배치한 파일은 Git 업로드에서 제외됩니다.

기존 설치는 봇 시작 시 직업 이미지 연결용 DB 컬럼을 자동 추가합니다. 캐릭터·파티 데이터를 초기화하지 마세요. 기존 캐릭터별 이미지와 `MAPLEBOT_CHARACTER_ICONS` 설정은 더 이상 사용하지 않습니다.

내장 이미지의 출처·권리 안내는 [NOTICE](../../maplebot/resources/job_icons/NOTICE.md)를 참고하세요.

레테 추가 업데이트에서는 기존 서버에도 한 번 자동 추가합니다. 이미 레테가 있으면 중복 생성하지 않고 빈 SD 연결만 채웁니다. 기존 비활성 상태는 유지하며 이후 이름 변경도 보존합니다.

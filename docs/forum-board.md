# 포럼 게시와 2열 파티 이미지

## 적용 순서

1. 새 코드와 의존성을 적용하고 봇을 재시작합니다. DB는 초기화하지 않습니다. 기존 캐릭터·직업·보스·파티 자료를 유지하며 게시 연결용 테이블이 자동 생성됩니다.
2. Discord 서버에 **포럼 채널**을 만듭니다. 포럼 채널 생성 메뉴가 없다면 서버의 커뮤니티 기능 설정을 확인하세요. 봇이 일반 텍스트 채널을 포럼으로 직접 변환하지는 않습니다.
3. 봇에 채널 보기, 메시지 보내기/게시글 만들기, Embed 링크, 파일 첨부, 메시지 기록 보기, 스레드에서 메시지 보내기, 스레드 관리 권한을 부여합니다. 포럼의 필수 태그 설정은 해제해야 합니다.
4. `/설정 파티배분표채널`에서 포럼을 지정합니다. 이 명령은 기본값만 바꿉니다.
5. `/파티배분표 게시`에서 포럼을 지정하고 변경을 확인합니다. 이미 게시한 이력이 있으면 마지막 게시 채널이 우선될 수 있으므로 **이전할 때는 채널을 명시**하세요. 게시 채널 지정·이전은 서버 관리자 전용입니다.
6. 포럼 안에 `스우 (익스트림)`처럼 보스별 게시글이 생성됩니다. 새 게시 준비가 모두 성공한 뒤 운영 세대를 전환하고 이전 일반 채널의 봇 게시물을 정리합니다. 준비가 실패하면 기존 운영 게시물을 유지합니다.

명령어의 채널 선택은 일반 텍스트 채널과 포럼을 모두 지원합니다. 기존 텍스트 채널 운영도 유지합니다. 같은 코드로 텍스트 채널을 사용해도 파티 이미지가 표시됩니다. 명령어는 봇 시작 시 기존 테스트 서버/전역 설정에 따라 다시 동기화됩니다.

## 화면

각 파티는 PNG 한 장입니다. 상단에 파티명·현재 인원/정원을 표시하고, 구성원은 2열로 배치합니다. 6인 파티는 3줄, 홀수 인원은 마지막 줄에 한 명, 빈 파티는 안내를 표시합니다. 직업 SD 아이콘·캐릭터명·직업·헥환·소유자명을 포함하며 Discord 아바타는 합성하지 않습니다. 긴 이름은 이미지 칸 안에서 말줄임하고, 원래 값은 DB에 유지합니다. 자료가 없는 직업은 공통 대체 이미지를 사용합니다.

이미지 아래의 소유자 멘션과 파티 편집·삭제 버튼은 실제 Discord 요소입니다. 멘션은 클릭할 수 있지만 갱신 때 사용자에게 알림을 보내지 않습니다. 탈퇴·소속 불명 사용자는 멘션 대신 상태와 이름을 표시합니다. 관리 패널·내 보스 버튼은 마지막 메시지에 둡니다. 이미지의 텍스트는 선택·클릭할 수 없고 모바일에서도 2열 이미지 전체가 축소됩니다.

공개 게시물과 개인 파티 관리 화면에 같은 이미지를 사용합니다. 개인 캐릭터 상세는 직업 아이콘 단독 표시를 유지합니다. 관리 화면은 기존처럼 한 개인 메시지에서 전환되며, 이미지 없는 화면으로 이동하면 이전 첨부를 제거합니다.

## 갱신·복구·정리

DB 변경이 먼저 성공한 뒤 작업자가 게시물을 갱신합니다. 이미지 내용이 바뀌면 첨부 이름도 바뀌고 이전 첨부를 교체합니다. 로컬 직업 이미지 교체는 `/파티배분표 새로고침`으로 반영합니다.

보스별 포럼 스레드와 메시지 경로를 DB에 저장합니다. 재시작 시 연결을 재사용하고, 보관·잠금 상태는 필요한 권한으로 해제한 뒤 갱신합니다. 게시글이 삭제되면 새로 생성합니다. 생성 후 DB 기록 전에 종료한 경우 봇 작성자의 정확한 버튼 메타데이터로 재연결합니다. 탐색 범위는 활성 게시글과 최근 보관 게시글 100개, 게시글별 최근 메시지 100개입니다. 이 범위를 벗어난 미기록 게시물은 수동 정리가 필요할 수 있습니다.

게시 중단·채널 이전 후 이전 세대의 봇 포럼 게시글은 삭제합니다. **게시글 안의 사용자 댓글도 함께 삭제**되므로 파티 안내 전용 포럼으로 운영하세요. 삭제 권한 오류 시 종료 안내로 바꾸고 정리를 재시도합니다. 보스 비활성화는 기존 게시글에 운영 중단 안내를 표시합니다.

## 기존 보스 순서 기능과의 차이

포럼 목록은 Discord의 최근 활동·생성일 정렬 등을 따릅니다. 봇의 보스 순서 값은 명령·관리 목록과 작업 순서를 유지하지만 포럼 목록의 고정 순서를 보장하지 않습니다. 포럼에서는 순서 변경만으로 게시글을 재생성하지 않아 기존 링크·댓글을 유지합니다. 일반 텍스트 채널의 순서 변경·재게시 동작은 유지합니다.

## 이미지와 글꼴

이미지는 1120픽셀 폭으로 생성하고 실제 표시 폭은 Discord가 결정합니다. 한글 표시를 위해 Noto CJK에서 한글·기본 문자를 추린 수정 글꼴 `MaplePartyUI`를 패키지에 포함합니다. 원본의 SIL Open Font License 및 저작권은 `maplebot/resources/fonts/LICENSE.txt`에 포함합니다. 개발 환경의 폰트 설치 여부와 관계없이 Windows/Linux에서 같은 파일을 사용합니다. 글꼴에 없는 이모지 등은 이미지에서 온전히 표시되지 않을 수 있으며 클릭 가능한 소유자 멘션은 이미지 밖에 유지합니다.

자동 테스트는 모의 Discord 전송과 실제 SQLite·Pillow로 수행합니다. 실제 Discord의 포럼 생성·권한 응답·PC/모바일 표시 결과는 사용자 테스트 서버에서 확인해야 합니다.
